# 🌱 MobiVerde

> **Mobilidade Sustentável & Caronas Inteligentes por IA**  
> *Conectando trajetos em tempo real, reduzindo custos, emissões de CO₂ e congestionamentos urbanos.*

---

## 📌 Sobre o Projeto

O **MobiVerde** é uma plataforma de mobilidade urbana colaborativa projetada para otimizar o deslocamento diário nas cidades. A aplicação utiliza cruzamento de rotas em tempo real para conectar motoristas e passageiros que estão indo para a mesma direção, eliminando a necessidade de agendamentos engessados.

Com foco em **sustentabilidade**, **eficiência de tempo** e **transparência financeira**, o sistema calcula automaticamente a contribuição justa por quilômetro percorrido e mensura o impacto positivo de cada viagem no meio ambiente e no tráfego urbano.

---

## 🚀 Principais Funcionalidades

- **Dupla Interface (Passageiro e Motorista):** Alternância simples de perfil dentro da própria aplicação.
- **Geolocalização via GPS (HTML5):** Captura automática da localização atual do usuário e ponto de encontro.
- **Solicitação em Tempo Real:** Sem necessidade de horários fixos. O motorista avista passageiros em sua rota enquanto dirige.
- **Cobrança Justa por KM:** O motorista define o valor cobrado por quilômetro e o passageiro visualiza o custo total transparente antes de solicitar.
- **Mapa de Aproximação Dinâmico:** Rastreamento em tempo real do veículo se deslocando até o ponto de encontro via *Leaflet.js*.
- **Métricas de Impacto Socioambiental:**
  - 🌱 **Pegada Ecológica:** Cálculo de emissão de CO₂ evitada.
  - 🚗 **Redução da Frota:** Menos veículos individuais circulando.
  - 📏 **Alívio Urbano:** Economia em metros de fila de congestionamento (1 carro a menos ≈ -6 metros de fila).

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript (ES6+)
- **Mapas e Geoprocessamento:** [Leaflet.js](https://leafletjs.com/) & OpenStreetMap API
- **Geolocalização:** HTML5 Geolocation API
- **Versionamento:** Git & GitHub
